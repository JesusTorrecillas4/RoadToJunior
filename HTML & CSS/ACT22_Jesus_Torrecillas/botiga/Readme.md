# MangaWorld Store 

> Tienda online especializada en mangas, figuras anime y productos otaku.

## Descripción

MangaWorld Store es una tienda online dedicada a la venta de mangas, figuras coleccionables y accesorios anime.
La web está dirigida a fans del manga y la cultura japonesa que quieren comprar productos de forma fácil y rápida.
La tienda incluye un catálogo de productos, carrito de compra y formulario de contacto.
Además, tiene un diseño responsive para móviles y ordenadores.

## Características principales

- Catálogo de mangas y figuras anime
- Carrito de compra
- Formulario de contacto validado
- Diseño responsive adaptable
